# Migration: `meta` → `facebook` (1.0.0, 2026-10-07)

Facebook Audience Network is now identified by its original name in every unified_ads API. (Its current brand is
"Meta Audience Network"; the SDK artifacts were always `com.facebook.android:audience-network-sdk` / `FBAudienceNetwork`.)
The rename itself changes no behaviour. Separately, in the same release the package became a full Audience Network adapter (it was a documented stub before); see `doc/setup/facebook.md`.

| Before | After |
|---|---|
| `AdNetwork.meta` | `AdNetwork.facebook` |
| `AdNetwork.meta.id == 'meta'` | `AdNetwork.facebook.id == 'facebook'` |
| package `unified_ads_meta` | package `unified_ads_facebook` |
| `import 'package:unified_ads_meta/unified_ads_meta.dart'` | `import 'package:unified_ads_facebook/unified_ads_facebook.dart'` |
| `MetaAdapter` | `FacebookAdapter` |
| JSON `"networks": {"meta": {…}}`, `"waterfall": ["meta"]` | `"networks": {"facebook": {…}}`, `"waterfall": ["facebook"]` |
| `doc/setup/meta.md` | `doc/setup/facebook.md` |

**`"meta"` is no longer accepted.** `AdConfigLoader` rejects it with `invalidConfig: $.networks.meta: unknown network`, and
`AdNetwork.tryParse('meta')` returns `null`.

Steps:
1. In `pubspec.yaml`, replace `unified_ads_meta` with `unified_ads_facebook`.
2. Replace `AdNetwork.meta` with `AdNetwork.facebook`, and `MetaAdapter` with `FacebookAdapter`.
3. In `ads_config.json`, rename the `"meta"` key and waterfall entry to `"facebook"`.

These packages were unpublished at the time of the rename (before 1.0.0), so no released version shipped the old names.
